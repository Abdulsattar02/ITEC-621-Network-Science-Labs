# ITEC-621 Network Science Labs

This repository contains all lab scripts for the course **ITEC-621: Network Science**. The labs cover essential concepts and practical applications in network science.

**Instructor Credit:**  
Special thanks to **Sir Uzair Anees Bhutto** for excellent guidance and teaching of the course concepts.

## Labs Overview

- **Lab 1–4:** Graph basics, connectivity, paths, and degree measures  
- **Lab 5:** Clustering and centrality measures  
- **Lab 6:** Random graphs and degree distributions (Erdős–Rényi)  
- **Lab 7–10:** Advanced network measures and applications  
- **Lab 11:** Bipartite networks (Author–Paper) and projections  
- **Lab 12:** Social networks and community detection
